# Citing OpenRoSDE

Summaries of the development history, requirements, vision, and goals of OpenRoSDE have been published in the papers below.

:::note

Cite these papers if you are using OpenRoSDE to implement your research!
It is crucially important to disseminate OpenRoSDE across the robotics research community.

:::

## 📄 Journal Paper

OpenRoSDE is the open-source reference implementation of the Software Development Environment (SDE) that this paper describes:

- L. El Hafi, G. A. Garcia Ricardez, F. von Drigalski, Y. Inoue, M. Yamamoto, and T. Yamamoto, "**Software Development Environment for Collaborative Research Workflow in Robotic System Integration**", in *RSJ Advanced Robotics (AR), Special Issue on Software Framework for Robot System Integration*, vol. 36, no. 11, pp. 533-547, Jun. 3, 2022.
  DOI: [10.1080/01691864.2022.2068353](https://doi.org/10.1080/01691864.2022.2068353)

```bibtex
@article{elhafi2022sde,
  author  = {El Hafi, Lotfi and
             Garcia Ricardez, Gustavo Alfonso and
             von Drigalski, Felix and Inoue, Yuki and
             Yamamoto, Masaki and Yamamoto, Takashi},

             Collaborative Research Workflow in
             Robotic System Integration},
  journal = {Advanced Robotics},
  volume  = {36},
  number  = {11},

  url     = {https://doi.org/10.1080/01691864.2022.2068353}

```
